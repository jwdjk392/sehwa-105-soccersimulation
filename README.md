# 축구 승부예측 프로그램

## 예측 알고리즘 작동 구조
경기 전반 45분 / 후반 45분 ==> 3분 단위 분배 30번 턴
### 사용자 개입
선수 교체
### 게임 진행 순서

### 파라미터
- 몇 턴인지?
- 선수들 능력치
	* 속도 (0 ~ 10)
	* 골 결정력, 정확도 (0 ~ 1f)
	* 체격 (0~10)
- 위치 
	* 경기장 N 분할 ==> 선수의 좌푯값 / X max Y max 180 x 90

### Flow
1. 선수별로 어떠한 행동을 할지를 확률을 계산해서 활동진행
2. 결괏값에 특별한 이벤트 발생하면 처리 (골)
3. 무한반복
