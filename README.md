# 축구 승부예측 프로그램

## 예측 알고리즘 작동 구조
경기 전반 45분 / 후반 45분 ==> 1분 단위 분배 90번 턴

### 선수 데이터
- 각 선수는 `name`, `position`, `speed`, `goal_rate`, `strength`를 가집니다.
- `position`은 `LCB`, `RCB`, `CB`, `LB`, `RB`, `DM`, `LCM`, `RCM`, `CM`, `AM`, `LW`, `RW`, `ST` 중 하나입니다.
- 포지션이 없는 기존 팀 데이터는 기본 진형 순서로 처리됩니다.

### 사용자 개입
선수 교체
### 게임 진행 순서

### 파라미터
- 몇 턴인지?
- 선수들 능력치
	* 속도 (0 ~ 10)
	* 골 결정력, 정확도 (0 ~ 1f)
	* 체격 (0~10)
- 위치 
	* 경기장 N 분할 ==> 선수의 좌푯값 / X max Y max 180 x 90

### Flow
1. 선수별로 어떠한 행동을 할지를 확률을 계산해서 활동진행
2. 결괏값에 특별한 이벤트 발생하면 처리 (골)
3. 무한반복
